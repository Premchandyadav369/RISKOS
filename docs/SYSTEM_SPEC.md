## 1. Scope & System Mission

RISKOS is an open, modular, zero-deception quantitative operating system engineered to execute multi-asset algorithmic strategies, real-time portfolio optimization, stochastic volatility calibration, and pre-trade risk gating.

### Invariant Principles
1. **Zero-Deception Data Integrity**: If an exchange is closed, prices do not fluctuate artificially. Settlement stamps are strictly preserved.
2. **Deterministic Numeric Invariants**: All order arithmetic must operate on raw numeric quantities ($Q_{\text{raw}} \in \mathbb{R}^+$); units and labels are strictly presentation-layer constructs.
3. **Hard Pre-Trade Gatekeeping**: No order may be routed to any execution gateway without prior deterministic validation of notional ceilings, price collars, and portfolio leverage bounds.

## 4. Disaster Recovery & Failover Topology

### High Availability Invariants
- **Stateless Computational Nodes**: All Python backend risk, optimization, and volatility routines are pure mathematical functions without hidden mutable session states.
- **Client Auto-Healing**: On page load, `safeInitFleet()` audits `localStorage` contents; any corrupt `NaN` or unformatted legacy variables are automatically purged and repaired using canonical `INITIAL_BOTS` values.
- **Circuit Breaker Persistence**: Emergency halt states are broadcast across all active browser windows via the `TerminalBus` event mesh and mirrored to localStorage (`DEFCON_STATE_V3`).
