# Model Card: Gaussian Hidden Markov Model (HMM) Regime Switching

## 1. Model Overview
The Gaussian HMM models financial asset returns as being generated by an unobserved discrete market state $S_t \in \{1, 2, \dots, K\}$ (e.g. Bull, Bear, Sideways, Crisis). Transitions between states follow a first-order Markov chain.

## 2. Mathematical Formulation
Let $r_t$ be daily asset log-returns.
$$P(S_t = j \mid S_{t-1} = i) = A_{ij}$$
$$r_t \mid (S_t = k) \sim \mathcal{N}(\mu_k, \sigma_k^2)$$

Parameters $\theta = \{A, \mu, \sigma, \pi\}$ are estimated via the Expectation-Maximization (Baum-Welch) algorithm maximizing the log-likelihood:
$$\ln P(r_{1:T} \mid \theta) = \sum_{t=1}^T \ln \left( \sum_{k=1}^K \alpha_t(k) \right)$$

Filtered state probabilities are computed via the Forward-Backward algorithm:
$$\gamma_t(k) = P(S_t = k \mid r_{1:T})$$

## 3. Assumptions & Limitations
- State durations follow a geometric distribution: $P(D = d) = (1 - A_{ii}) A_{ii}^{d-1}$.
- Assumes Gaussian conditional emission densities within each state.

## 4. Failure Modes & Numerical Safeguards
- **Degenerate Covariance**: If a state captures very few points, variance can collapse to zero. RISKOS enforces a variance floor $\sigma_k^2 \ge 10^{-6}$.
- **Zero Transition Probabilities**: Laplace smoothing applied to rows of transition matrix $A$.
